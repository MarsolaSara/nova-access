NOVA ACCESS • INICIAR NO WINDOWS
================================

1) Abra a pasta "backend" no IntelliJ.
   Rode a classe NovaAccessApplication.java (botão verde ao lado do main).
   OU abra PowerShell dentro de "backend" e digite:
      mvn spring-boot:run

2) Abra OUTRO terminal dentro de "frontend":
      npm install
      npm run dev

3) Abra: http://localhost:5173

4) Clique em "Usar conta demo" e depois "Entrar na minha conta".
